# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-20

### Added
- Initial public release of Multiple-Object-Tracking for multi-object detection and tracking in videos using YOLOv8, ByteTrack, PyTorch, and OpenCV.
- Google Colab notebook (`Derin_Öğrenme_ve_Yapay_Sinir_Ağları.ipynb`) for real-time object detection and tracking.
- Project documentation (`README.md`), `requirements` file, and MIT `LICENSE`.
